# Radical Simplify Workout

Generated practice for simplifying radicals — Math 2201, Unit 4 (Radicals), with worked and faded openers, step-by-step entry, and "Show this step" help in every mode.

**Indicators:** 1.1, 1.2, 1.3, 1.4, 1.5

**Modes:**

1. **Simplify — numbers** — square and cube roots; every radicand is built from a coefficient × leftover so the simplified form is always non-trivial.
2. **Simplify — variables** — square roots (exponents halve) and cube roots (exponents split in triples), one variable then two; variables are assumed non-negative.
3. **Mixed ↔ Entire** — converting mixed radicals to entire radicals and back, square and cube roots.
4. **Compare and Order** — three mixed-form radicals; students enter the three entire-radicand values first, then the ordering.
5. **Restrictions** — the boundary and relation (≥ or >) for a radical expression, including the strict-inequality case with the radical in a denominator.
6. **Mixed set** — all modes in one session.

Each mode opens with a fully worked example, then a faded item (first steps shown, final step blanked), then generated items. A session is 10 items; the counter tracks finished items and notes help used, with no penalty.

Single self-contained `index.html` (no external assets). Open it in any browser — Chromebook and mobile friendly.

Verification: `node harness.js` draws 2,000 items per generator shape, checks uniqueness (≥ 50 per shape), and recomputes every key with independent math (0 mismatches required).
